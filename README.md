# 🤖 AI Code Reviewer

An AI-powered Code Review platform built with React, Node.js, Express, and Google's Gemini API.

Users can review code, get explanations, chat with AI, download reports, and manage review history.

---

# ✨ Features

## 🤖 AI Code Review
- Review code using Gemini AI
- Detect errors and bugs
- Suggest improvements
- Best practices
- Optimized code generation
- Code Quality Score

---

## 📖 Explain Code
- Explain code line-by-line
- Beginner-friendly explanation
- Markdown support

---

## 💬 Ask AI
- Ask questions about the generated review
- AI answers using the review context
- Markdown formatted responses

---

## 📊 Dashboard
- Language Usage Chart
- Review Statistics
- Review Count
- Code Metrics

---

## 📂 Review History
- Save reviews locally
- Search reviews
- Filter by language
- Delete single review
- Clear all reviews
- Export CSV
- Export JSON
- Import JSON

## 📄 Report
- Download Review as PDF
- Copy Review

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Pithiyachirag/AI-Code-Reviewer.git
```

## Frontend

```bash
cd client
npm install
npm run dev
```

## Backend

```bash
cd server
npm install
npm start
```

# 🔑 Environment Variables

Create `.env`
