# 🤖 AI Code Reviewer

An AI-powered Code Review platform built with **React.js**, **Node.js**, **Express.js**, and **Google Gemini AI**.

Analyze code, explain code, ask AI questions, download reports, and manage review history.

# ✨ Features

- 🤖 AI Code Review
- 📖 Explain Code
- 💬 Ask AI About Review
- 📊 Review Dashboard
- 📈 Review Analytics
- 📂 Review History
- 📄 Download PDF
- 📊 Export CSV
- 📄 Export JSON
- 📥 Import JSON
- 🌙 Dark Mode
- 📱 Responsive Design

# ⚙ Installation

```bash
git clone https://github.com/Pithiyachirag/AI-Code-Reviewer.git
```

## Frontend

```bash
npm install
npm run dev
```

## Backend

```bash
cd server

npm install

npm start
```
